## v1.0.3 — 2026-08-02

### Charts
- Decluttered taxi labels (max 2 per taxiway), smaller badges, more gate ticks/labels
- Layer toggles: Taxi, Gates, Legend, Traffic
- Follow mode — keeps own aircraft centered on the diagram
- Improved taxiway strokes and badge-style designators

### Aircraft
- Schematic 3-column door layout (left chips · plane · right chips)
- Ground services: CHOCKS, GPU, ASU, PCA, SERVICES (SET / OFF)
- Boarding requires DOOR 1L open (message only when blocked)

### Chat
- @mention autocomplete (full pilot names from online / recent chat)
- Optional mention alerts (sound + strip flash) — Settings → Notifications
- Share origin / dest ATIS into the channel

### Other
- Leaderboard tab (Board) — weekly hours & flights via backend
- Settings update banner can show changelog notes for a newer version
